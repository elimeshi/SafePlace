# Navigation

This app uses `expo-router` (file-based routing under `apps/mobile/app/`).
This `src/navigation` folder is for navigation *helpers* (typed route
params, deep-link builders, navigation-state utilities) — not route
definitions themselves, which belong under `app/`.
