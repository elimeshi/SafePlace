**Icon** — curated Lucide outline glyph (24×24, 2px stroke, `currentColor`). Safe-Place ships no icon set of its own; this is the flagged Lucide substitution. Group-gallery icons (feed-spec §2.2.4) are out of scope.

```jsx
<Icon name="heart" size={20} />
<Icon name="bell" color="var(--color-primary)" />
```
See `ICON_NAMES` for the full set.
